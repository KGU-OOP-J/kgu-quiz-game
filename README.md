# WHO’S NEXT? — 인물 카드 퀴즈 어드벤처

Java Swing 기반 로컬 싱글 플레이 게임입니다. 과학자·교수님·한국사·아이돌 네 마을의 80명과 난이도별 총 1,200문제로 연습하고, 학습형 배틀과 마을 보스에 도전합니다.

## 실행

**JDK 25 이상**이 필요합니다. 저장소 루트에서 실행하세요.

```sh
./gradlew run
```

Windows에서는 `run.bat`을 실행하거나 `gradlew.bat run`을 사용합니다. 사용자 ID는 로컬 세이브 선택용이며 비밀번호 인증이나 온라인 계정이 아닙니다.

## 플레이 흐름

1. 처음 로그인하면 6단계 튜토리얼이 표시됩니다. 완료 상태는 사용자별로 저장되며 메인에서 다시 볼 수 있습니다.
2. 연습에서 정답을 맞혀 단계 카드를 얻습니다. 매 판 서로 다른 10명과 난이도 내 무작위 문제가 출제됩니다.
3. **카드 장착**에서 지원 카드 1장을 사용합니다. 획득 카드 장착·숙련도를 관리합니다. 현재 전투에서 집중 카드의 경험치 증가가 적용되며, 다른 종류를 공격·방어 스킬로 소개하지 않습니다.
4. **마을 지도**에서 인물 도전 → 서로 다른 인물 3명 승리 → 마을 보스 순으로 진행합니다.
5. 완료 보상으로 XP·코인을 얻습니다. 레벨 업, 상점 아이템 구매, 도전과제 보상 수령, 오답 복습이 가능합니다.

### 현재 전투 규칙

- 일반 도전과 보스 모두 **선택한 인물·난이도의 5문제**를 풉니다.
- 상대 HP는 60, 정답마다 20 감소하며 **3회 성공하면 승리 조건**을 충족합니다. 학습을 위해 남은 문제도 진행합니다.
- 남은 문제와 보호 부적 재도전을 고려해도 승리할 수 없으면 조기 종료합니다.
- 공격·방어 선택이나 강공격 스킬 대신 4지선다 문제에 집중합니다.
- 아이템은 한 전투에 하나: 분석 렌즈(현재 오답 보기 1개 제거), 보호 부적(첫 오답 재도전), 정보 물약(인물 정보 열람).
- 승리 시 상대 인물의 해당 난이도 카드 1단계를 얻습니다. 별은 승리 1개 + 최초 정답 4개 이상 1개 + 아이템 미사용 1개입니다.
- 연습은 서로 다른 인물 10문제입니다. 정답 카드·경험치 보상과 별도로, **10문제 전부 정답인 완료 판에만 5코인**을 줍니다. 오답 복습은 별도 보상 규칙을 사용합니다.

### 최종 시연본

`feat/final`은 통합본 위에 화면 흐름, 연습 연출, 학습 기록, 시연 모드를 개선한 브랜치입니다.

- **[실행·치트 사용법·발표 준비 및 기능 정리](docs/FINAL_PRESENTATION.md)**
- 로그인 ID `admin` 또는 `cheat`: 마을·보스·교수님 도전 해제 및 도감 전체 카드 미리보기. 무한 코인·아이템 기능은 아닙니다.
- 최종 교수님 도전 대상은 현재 **이은정 교수님**입니다.

## 저장

- 기존 카드 파일: `saves/<ID>.txt` (이전 세이브 유지)
- XP·코인·장비·재고·숙련도·도전·문제 기록: `saves/<ID>.txt.progress`
- 설정: `settings.properties`

진행도 파일은 원자적 교체로 저장하며, 실패한 변경은 메모리에 적용하지 않습니다. 완료 보상은 세션 ID로 중복 지급을 방지합니다. 상점 아이템은 게임 코인으로만 구매하며 실제 결제는 없습니다. 전투 중단 시 사용한 아이템은 반환되지 않습니다.

## 검증

```sh
./gradlew test              # 신규 게임 흐름 + 기존 배틀 모듈 JUnit 테스트
./gradlew integrationChecks # 실제 1,200문제·저장 오류·화면 흐름을 메모리에서 검증
./gradlew build             # 두 검증을 모두 포함
```

기존 배틀 브랜치의 일부 테스트는 실제 JFrame을 사용하므로 Linux CI에서는 X 서버 또는 `xvfb-run ./gradlew test`가 필요합니다. `integrationChecks`는 디스플레이 없이 실행됩니다. UI 미리보기는 테스트 후 `build/*-preview.png`에 생성됩니다.

## 코드 구조

- `application`, `window`: 앱 시작, 사용자 세션, 화면 생명주기
- `game/feature`: 출제, 연습, 전술 배틀, 완료 보상
- `game/view`: 통합 연습·배틀·결과 UI
- `progression`: 진행도 저장, 상점, 도전과제, 인물 카드 버프
- `adventure`: 마을 진행·상점·도전과제·장착·오답 노트와 튜토리얼
- `collection`: 지도형 도감과 단계 카드
- `factory`, `manager`, `model`: 기존 데이터·카드 저장과 모델
- `ui/battle`, `battle`: 배틀 브랜치의 재사용 효과와 독립 모듈 (통합 전투에서 `ImpactCard` 효과 사용)

`runIntegration`은 기존 배틀 모듈의 **테스트용 데모**입니다. 실제 게임 실행은 `run`입니다. `docs/reference/`의 이전 화면 소유권 문서는 과거 프로토타입 기준입니다.

현재 시연 규칙은 [최종 발표 문서](docs/FINAL_PRESENTATION.md)를 기준으로 확인하세요. `docs/GAMEPLAY.md`에는 이전 전술 배틀 설계가 남아 있어 현재 규칙과 다를 수 있습니다.
