# 회의 결정사항 반영과 남은 연결 작업

## 반영한 내용

- 1280×960 기준의 중앙 1인 전투 화면. 문제와 보기는 굵게 표시하며 큰 문제·보기 영역을 유지합니다.
- 공격/방어 구분 제거. 선택한 분야 또는 무작위 분야에서 상대 한 명을 보여주고 HP 0까지 공격합니다.
- 다음 버튼 제거. 정답은 타격 후 1초, 오답은 2.4초 후 자동으로 다음 문제 또는 결과로 진행합니다. 일시정지 버튼은 제공하지 않습니다.
- 성공 시 대상 인물의 해당 난이도 카드 한 장만 저장하고 중복을 방지합니다. 80명×3단계의 240장 체계는 기존 도감 기준입니다. 중복·실패가 있으므로 240번의 플레이만으로 항상 완성되는 것은 아닙니다.
- 주인공은 졸업을 앞둔 대학교 4학년. 교수님 실종과 기억 회복을 중심으로 문구를 수정했습니다. 대학원생 엔딩은 구현하지 않습니다.
- 전투 준비 단계의 이름 목록과 전투 중 이름 라벨을 숨겨 이름이 답인 문제의 직접 노출을 줄였습니다. 질문 본문·이미지 자체에 답이 포함된 사례는 데이터 담당의 별도 검수가 필요합니다.

## 데이터 추가 호환성

엔진은 입력 목록의 길이로 진행하며 문제 수를 3개 또는 6개로 고정하지 않습니다. 예: `new BattleEngine(target, questions, 5)`는 정답 공격 다섯 번으로 격파합니다. HP는 60이며 적중 횟수에 맞춰 피해를 계산합니다. 현재 데이터의 기본 3문제는 2회 적중으로 격파하는 확인용 설정입니다.

브랜치 테스트 자료는 `src/test/resources/integration/data/{분야}.txt`, 별도 통합본은 `data/{분야}.txt`입니다. 같은 인물의 문제를 추가할 때 기존 탭 형식을 지킵니다.

```text
이름    소개    정보1    정보2    정보3
중    질문    보기1    보기2    보기3    보기4    정답번호(1~4)
```

인물 정보 아래에 원하는 수의 문제 줄을 두고 다음 인물 정보를 이어 적습니다. 현재 데이터 어댑터는 난이도당 최소 3문제인 인물을 제공합니다. 기존 통합본 문제 로더의 정확히 10줄 제한은 제거했습니다. 데이터 파일을 편집한 뒤 앱을 다시 시작하세요.

문제별 힌트와 해설은 BattleQuestion의 입력 필드로 전달할 수 있지만 현재 TXT에는 해당 열이 없습니다. 임의로 열을 추가하지 말고 문제 담당과 형식을 합의하세요.

## 팀과 정할 사항

- 카테고리별 대표자와 능력: 과학자 힌트, 아이돌 응원 등. 지급·소모·중첩·지속 시간과 한국사 능력은 미확정. 현재 힌트/응원 버튼은 비활성입니다.
- 마을 → 일반 전투 → 마왕성 맵, 챕터 해금에 필요한 수집 수량, 교수님 스테이지 연결은 맵/도감 담당과 합의가 필요합니다. 이를 이미 구현한 것처럼 표시하지 않습니다.
- 다른 팀 화면도 1280×960로 통일하는 작업은 각 화면 담당에게 공유해야 합니다. 배틀 변경만으로 다른 화면의 레이아웃까지 바뀌지는 않습니다.
- 새 시작 설정과 결과 API 반영은 담당자와 협의. 이 브랜치에서는 test 패키지의 참고본만 연결하고 팀원 원본은 보존합니다.

## 코드 읽는 순서

1. BattleEngine: 입력 문제·HP·정답·종료 판정.
2. BattleScreen: 화면 구성과 버튼, 자동 진행.
3. ImpactCard: 시각 효과만 담당.
4. BattleSetupScreen: 카테고리에서 준비된 상대 한 명을 제시.
5. 테스트 BattleFlowPanel/BattleService: 데이터·화면·카드 저장 연결.

## 협업 규칙 확인 범위

로컬 docs/CONTRIBUTING.md와 docs/reference/TEAM_MODULE_GUIDE.md를 확인했습니다. 기능 브랜치에서 작업, 담당 패키지 중심 변경, UI·로직 분리, clean build 검증, PR에 변경/테스트 결과 기재를 따릅니다. 이전 세션의 develop 병합 중단 요청을 유지합니다.

GitHub 연결 도구는 해당 문서 조회에 404를 반환했고 Git 원격 조회는 인증을 요구했습니다. 따라서 현재 원격 최신 문서를 확인했다고 주장하지 않습니다. 이 작업에서 Commit, Push, PR 생성은 하지 않았습니다.

## 교수님 필살기 및 글꼴

문제 본문과 보기에는 굵은 글꼴을 사용합니다. 교수님 전투에서 문제를 모두 소진했는데 상대 HP가 남으면, 마지막 정답 안내 뒤 약 2.8초 동안 짧은 정적 → 빨간 F 도장 낙하·충격파·화면 흔들림 → “형편없구만…” 대사를 재생하고 실패 결과를 전달합니다. 승리 또는 다른 카테고리에는 교수님 필살기를 재생하지 않습니다. 이 연출은 확정된 실패 결과를 표현하며 별도의 플레이어 HP나 추가 보상을 만들지 않습니다. 메뉴 이탈 시 타이머를 중지하고 결과 콜백을 보내지 않습니다.
