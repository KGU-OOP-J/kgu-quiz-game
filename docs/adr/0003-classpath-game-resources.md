# ADR-0003: 읽기 전용 게임 데이터를 classpath로 로드

- Status: Accepted
- Date: 2026-11-27

## Context

카드 이미지 240장이 저장소 루트와 번들에 같은 내용으로 있었다. 일반 게임은 실행 작업 폴더를 기준으로 루트의 문제, 카드, 지도와 대본을 읽었다. 루트와 번들의 문제 파일은 서로 달랐으므로 실제 플레이에서 사용하는 데이터를 보존해야 했다.

## Decision

사용자 요청에 따라 배포하는 이미지는 classpath에서 읽는다. 일반 게임이 사용하던 문제와 대본도 기존 리소스 경로에 두고 같은 방식으로 로드한다. 이미지 논리 키와 기존 세이브 파일 형식을 유지한다.

루트 파일을 빌드 때 복사하면 실행 작업 폴더 제약은 줄지만 소스와 번들의 중복 관리가 남을 수 있다. 외부 파일을 우선하는 방식은 실행 위치에 따라 게임 데이터가 달라질 수 있다.

## Consequences

- 배포 JAR에 게임 시작에 필요한 읽기 전용 데이터가 함께 들어간다.
- 기본 문제·이미지를 바꾸려면 배포물을 다시 빌드한다. 플레이어 저장과 설정은 쓰기 가능한 파일 경로를 계속 사용한다.

## Compliance

`integrationChecks`로 번들 문제와 카드 이미지를 확인하고, 프로젝트 루트 외부에서 배포 JAR을 실행해 지도, 카드, 대본을 확인한다.
