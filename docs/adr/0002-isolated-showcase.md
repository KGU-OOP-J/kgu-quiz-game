# ADR-0002: 시연 데이터 격리

- Status: Proposed
- Date: 2026-11-27

## Context

F1에서 로그인이나 진행 조건을 거치지 않고 전투 연출과 여러 화면을 시연해야 한다. 답안 제출과 보상 지급은 일반 플레이에서 디스크에 진행 상황을 저장한다.

## Decision

별도 Swing 창에 같은 화면과 기능을 등록하고, 시연 세션과 설정을 새 임시 디렉터리에 두는 방식을 제안한다. 실제 전투의 판정과 애니메이션을 재사용하며 시연 장면마다 세션을 새로 만든다.

현재 플레이어를 시연 상태로 바꾸면 창 하나로 처리할 수 있으나 저장 호출과 타이머 진행까지 되돌려야 한다. 시연 전용 모형은 저장이 단순하지만 실제 연출과 결과 화면의 변경을 별도로 따라가야 한다.

## Consequences

- 플레이 중인 저장 파일을 시연에서 참조하지 않고 실제 연출을 재생할 수 있다.
- 시연 동안 창과 세션이 하나 더 생성되며 임시 파일은 정상적인 JVM 종료 때 정리된다.

## Compliance

플레이 창에서 F1을 열어 승리·패배·구출을 실행하고, 기존 플레이어의 저장 파일과 설정을 비교한다.
