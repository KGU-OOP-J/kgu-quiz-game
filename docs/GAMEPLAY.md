# 통합 게임 시스템

## 브랜치 통합

`develop`에서 로컬 merge commit으로 `chore/new-architecture`, `feat/quiz-five`, `feature/main-screenv2`, `feature/result-screen`, `view/1-collection-map`, `feature/QuestionScreen`, `feature/battle-screen`을 통합했습니다. 원격 push나 새 브랜치는 사용하지 않았습니다.

구조가 다른 두 프로토타입의 내비게이션을 중복으로 실행하지 않습니다. 연습 화면은 통합 `QuestionView`에 이미지·보기 중심 레이아웃을 이식했고, 신규 배틀 모듈의 `ImpactCard`를 통합 퀴즈 전투에서 재사용합니다. 기존 독립 배틀 모듈과 테스트는 유지했습니다.

## 성장·경제

- 시작 레벨 1, 코인 120. 최초 프로필이 없을 때만 기본값을 사용합니다.
- 현재 레벨에서 다음 레벨에 필요한 XP: `100 + (level - 1) * 50`.
- 최대 레벨 100. 배틀에는 플레이어 HP가 없으며 레벨은 전투 피해량에 영향을 주지 않습니다.
- 완료 XP: 연습 정답당 8, 복습 정답당 6, 배틀 정답당 12.
- 배틀 승리 보너스 XP: 일반 60, 보스 120. 집중 카드의 XP 증가가 추가 적용됩니다.
- 완료 코인: 연습·복습 정답당 4, 배틀 정답당 6. 일반 승리 +40, 보스 승리 +100.
- 완료하지 않고 중단한 판의 XP·코인은 지급하지 않습니다. 연습에서 이미 저장한 카드는 유지됩니다.
- 분석 렌즈 40코인: 현재 문제의 오답 보기 1개 제거. 보호 부적 50코인: 첫 오답 하나를 마지막에 재도전. 정보 물약 60코인: 전투 중 인물 정보 열람.
- 각 아이템은 종류별 보관 99개, 종류를 합쳐 전투당 하나만 사용. 사용 가능 여부 검사 → 재고 영속 차감 → 효과 적용 순서입니다.
- 도전과제 10종: 튜토리얼, 첫 승리, 10승, 정답 30개, 콤보, 레벨, 수집, 보스, 별, 완벽 승리.

## 지원 카드

획득한 카드만 1장 장착할 수 있습니다. 카드가 없어도 견습 탐험가로 참가할 수 있습니다.

기존 카드의 성향·장착·숙련도 저장은 유지합니다. 전투 피해량과 성공에 필요한 정답 수는 장착 카드나 레벨에 따라 바뀌지 않습니다. 집중 성향의 기존 전투 XP 보너스(`strength × 5%`)만 유지하고, 다른 성향의 공격·방어·자원 효과는 적용하지 않습니다.

연습 완료 시 획득 인물, 배틀 승리 시 상대와 장착 카드의 숙련도가 각각 +1입니다. 같은 인물은 한 판당 한 번만 증가합니다.

## 5문제 학습 전투

남은 문제와 사용 가능한 보호 부적의 재도전을 합쳐도 3정답에 도달할 수 없으면 조기 패배합니다. 미응답 문제는 학습 기록에 추가하지 않습니다. 승패가 확정되면 마지막 일격 연출이 완료된 뒤 결과로 이동합니다.

- 모든 전투에서 선택한 상대·난이도의 서로 다른 문제 5개를 준비합니다. 자료가 부족하면 시작 전에 오류를 알립니다.
- 상대 HP 60, 정답 피해 20. HP 0 도달 후에도 남은 문제를 모두 풀고 마지막에 승리·구출을 확정합니다.
- 최초 정답 3개 이상이면 승리합니다. 내 HP·공격 방식 선택·반격 수치·스킬 자원은 없습니다.
- 분석 렌즈는 현재 문제의 오답 보기 하나를 무작위로 제거합니다. 제거한 보기가 선택돼 있으면 선택을 해제합니다.
- 보호 부적은 원래 5문제를 마친 뒤 첫 오답 하나를 다시 출제합니다. 보기 위치를 반드시 바꾸고 재도전은 딱 한 번만 허용합니다. 오답이 없으면 추가 문제 없이 끝납니다.
- 재도전 정답은 성공 조건만 +1 보충합니다. 최초 정답률·콤보·정답 XP·정답 코인·교수님 해금 정답 수에는 추가하지 않으며, 오답 노트도 유지합니다. 재도전으로 승리하면 기존 승리 보상은 지급합니다.
- 정보 물약을 사용하면 이번 전투 동안 인물 소개·정보를 열람할 수 있습니다. 예전 `TONIC` 저장 키는 유지하여 보유 물약이 사라지지 않습니다.
- 아이템은 답안 제출 전에 전투당 하나만 사용합니다. 재고·상태 검사 → 영속 재고 차감 → 효과 적용. 실패한 저장은 아이템 효과를 적용하지 않습니다.
- 정답 타격·HP 감소·화면 흔들림을 재사용합니다. 오답은 적 타격 없이 피드백을 표시합니다. 정답 2.2초, 오답 3.2초 후 자동 진행하며 Enter는 제출에만 사용합니다.
- 승리 연출 후 기존 구출 대화·결과로 연결합니다. 교수님 최종 실패에는 약 2.8초 F 도장 효과를 재생합니다. 이탈 시 타이머와 후속 콜백을 취소합니다.

## 도전·반복 플레이

- 네 마을에서 원하는 상대·난이도를 선택합니다.
- 같은 마을의 서로 다른 상대 3명에게 승리하면 보스가 열립니다. 동일 인물을 여러 난이도로 이겨도 해금 인원은 한 명입니다.
- 승리 1별, 최초 정답 4개 이상 추가 1별, 아이템 미사용 추가 1별. 상대·난이도·일반/보스별 최고 별을 저장합니다.
- 지도, 결과, 메인 메뉴가 다음 목표를 안내합니다.
- 연습은 전체 20명 중 10명을 중복 없이 선택하며 각 인물의 난이도 내 5문제를 활용합니다.
- 최근 40문제를 우선적으로 피하고 보기 순서도 섞습니다. 정답 인덱스도 함께 변환합니다.
- 문제 ID는 인물·분야·난이도·원문·원본 보기를 SHA-256으로 해시합니다. 파일 줄 이동이나 매 판 보기 셔플에 영향받지 않습니다.
- 오답 기록은 사용자별로 저장하고, 복습에서 맞히면 제거합니다. 복습은 최대 10문제, 카드 중복 보상 없이 XP·코인을 지급합니다.

## 영속성·생명주기

기존 카드 TSV를 그대로 유지하고 버전 1의 Properties 사이드카에 새 진행도를 저장합니다. 파일을 임시 경로에 쓴 후 atomic move로 교체하며 지원하지 않는 파일 시스템에서는 replace move로 대체합니다. 잘못된 버전이나 음수 수치는 조용히 초기화하지 않고 오류로 표시합니다.

답안 기록 저장에 실패하면 제출 전 상태를 유지합니다. 카드와 프로필 파일은 각각 중복 방지되며 결과 화면에서 저장 실패를 재시도할 수 있습니다. 완료 보상의 UUID 정산 기록은 재시도·재로그인에서 XP·코인·숙련도가 이중 지급되는 것을 방지합니다. 단, 진행 중인 판의 재개는 지원하지 않습니다.

튜토리얼 완료는 마지막 버튼에서 저장합니다. 미루면 다음 로그인에 다시 나타납니다. 다시 보기는 추가 보상을 지급하지 않으며 튜토리얼 도전과제는 한 번만 수령합니다.

화면 이탈 시 배틀·결과·도감·메뉴 애니메이션 타이머를 중단합니다. 결과 효과도 유한 시간 후 종료됩니다. 다른 ID로 다시 로그인할 때 이전 사용자 화면과 이벤트를 해제합니다.

## 검증 범위

- `ProgressStoreTest`: 저장 실패·재로드·도전과제 중복·코인·재고·경험치·숙련도.
- `QuizBattleTest`: 5문제 완주, 성공 기준, 아이템 한 개 제한, 재도전 분리 평가, 별·보상·입력 잠금·문제 ID.
- `AdventureFlowTest`: 실제 데이터로 튜토리얼 버튼·상점·장착·전투·보스 해금·오답 복습·재로그인용 저장 검증 및 UI 렌더링.
- `integrationChecks`: 기존 공통 구조·전체 데이터·카드 이미지·파일 오류·UI 버튼·저장 재시도의 메모리 검증.
- 기존 배틀 브랜치 JUnit 테스트도 유지됩니다.

## 후속 확장 후보 (미구현)

일일 시드 도전, 제한된 카드 조합 시너지, 분기형 탐험, 보스별 고유 패턴, 더 풍부한 해설·출처, BGM과 접근성 옵션이 적합합니다. 온라인 랭킹이나 실시간 PvP보다 현재의 로컬 저장·학습·수집 루프를 먼저 플레이테스트하고 수치를 조정하는 것을 권장합니다.

## 이번 변경의 통합 경계

`game/feature/BattleEngine`, `game/view/BattlePanel`이 정식 전투입니다. `battle/`, `ui/battle/BattleScreen`의 독립 프로토타입은 참고·회귀 테스트용으로 유지하며 정식 게임 흐름에서 실행하지 않습니다. `ImpactCard`와 `FinalAttackEffect`만 시각 효과로 재사용합니다. 새 타이머는 HP·승패·저장 데이터를 변경하지 않으며, 명령은 `BattleGUIEvent` → `GameFeature`를 통해 처리합니다.
