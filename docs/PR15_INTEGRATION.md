# PR #15 통합 안내

## 유지한 기능과 새 기능

- PR의 `core/domain` 구조, classpath 리소스, 공통 버튼, F1 시연, 보스 페이즈, 지원 카드, NEW 저장, 카드 획득 연출, 엔딩을 유지한다.
- `feat/final`의 도감 정화, `admin`/`cheat`, 이번 판 답안 기록·오답만 복습, 연습 카드 피드백, 내부 규칙·아이템 안내를 새 패키지로 연결했다.
- 지도는 분야별 서로 다른 인물 10/20 수집 시 섬 정화, 교수님 마을 해금 시 전체 정화를 유지한다. 정화 도중에는 마우스 확대를 잠시 생략해 폐허/정상 이미지가 중간에 갑자기 교체되지 않게 했다.
- 연습은 정답 단계 카드와 완료 XP(정답당 8)를 유지한다. 만점 완료 판에만 5코인을 지급하며 오답 포함·중도 종료 시 코인은 없다. 연습에는 난이도 보상 가산을 적용하지 않는다.
- 일반 도전 5문제(3개 정답), 마을 보스 10문제(페이즈별 3→4개), 교수님 15문제(3→3→4개). 일반 전투와 각 페이즈는 통과 조건 충족 후에도 남은 문제를 진행한다.
- 복습은 정답당 XP 6·코인 4 유지. 이번 판 오답 복습은 이전 보상 저장 성공 후에만 새 세션으로 이동한다. 재도전은 최초 답안 기록을 덮어쓰지 않는다.

## 실행 / 시연

JDK 25 이상. 저장소 루트에서 Windows PowerShell은 `.\gradlew.bat run`, WSL에서 Windows Java를 사용할 때는 `cmd.exe /c "gradlew.bat run"`.

- `admin` 또는 `cheat` 로그인: 마을·보스 해금과 전체 도감 미리보기. 실제 카드 소유·성적을 가짜로 채우지 않는다.
- F1: 로그인 전에도 장면 시연 메뉴. 별도 임시 저장으로 일반 계정을 보호한다.
- `gradlew.bat run --args="--showcase=RESCUE"`: 교수님 구출 시연.
- `gradlew.bat run --args="--showcase=ENDING"`: 엔딩 시연.
- 과거 `runIntegration`은 별도 테스트용 데모다. 통합 게임은 `run`을 사용한다.

## 검증 범위

기존 검사가 가정하던 단일 5문제 보스, 최초 승리 보상, 동기 화면 전환을 새 규칙에 맞췄다. 테스트를 무시하거나 비활성화하지 않고 다음 동작을 추가 확인한다.

- 만점/오답/중도 종료 및 완료 보상 중복 방지
- 교수님 3페이즈의 서로 다른 15문제·HP·최종 카드 단계
- 이번 판 오답만 복습 및 저장 실패 시 원래 세션 보존
- 시연 계정의 실제 진행도 비변경
- 단계별 NEW의 저장·재읽기·개별 해제
- 정화는 단계 카드 수가 아닌 서로 다른 인물 수로 판단
- 오답 카드 사라짐 및 다음 카드 정상 표시
- 실제 Swing 버튼·타이머를 통한 공격·승패 연출과 작은 창 조작

음원 파일은 아직 없는 상태라 해당 효과음은 생략된다. 이 점은 시연 전에 공유해야 한다. 기존 문서의 무보상 연습 및 테스트 8개 실패 기록은 PR 개발 당시 기록이며, 통합 후 검증 결과는 아래에 기록한다.
