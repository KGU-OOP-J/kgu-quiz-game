# Final Game Polish 규칙

구현 계획: [ONE_STEP_MORE_PLAN](ONE_STEP_MORE_PLAN.md). 요구사항: [one_step_more](one_step_more.md).

## 통합 규칙: 연습 만점 5코인 유지

PR #15 통합 시 `feat/final`의 연습 규칙을 유지했다. 연습 정답으로 해당 단계 카드를 얻고, 완료 시 정답당 XP 8을 지급한다. 10문제 만점 완료 판만 5코인을 받고 오답 포함/중도 종료에는 코인을 지급하지 않는다. 연습은 일반 학습 정답·해금 기록에도 반영한다. 난이도 가산은 전투에만 적용한다. REVIEW는 기존 정답당 XP 6·코인 4를 유지한다.

기존 무보상 연습 설명은 PR 작업 중의 이전 제안이며 이 통합 규칙으로 대체한다.

## 전투와 페이즈

| 도전 | 문제 구성 | 페이즈별 통과 조건 |
|---|---|---|
| 일반 인물 | 선택 난이도 5문제 | 정답 3개 |
| 마을 보스 | 서로 다른 두 난이도, 각 5문제 | 정답 3개 → 4개 |
| 이은정 교수님 | 하·중·상 각 5문제 | 정답 3개 → 3개 → 4개 |

마을 보스는 과학자 **앨런 튜링**, 한국사 **김구**, 아이돌 **영케이**다. 해당 마을의 서로 다른 인물 3명에게 승리하면 열린다. 교수님 해금은 기존의 타 분야 서로 다른 문제 30개 정답 조건을 유지한다.

마을 보스의 두 번째 난이도는 하→중, 중→상, 상→하다. 문제 데이터는 인물별 난이도마다 5개이므로 같은 문제를 반복하지 않기 위해 난이도를 구분한다. 최종 교수님은 항상 하→중→상이며, 상 단계 보상을 지급한다.

HP는 페이즈 통과 정답 수 × 20이다. 정답마다 20 감소하며 마지막 페이즈를 통과해야 승리한다. 목표에 도달해도 해당 페이즈의 남은 문제를 풀고 넘어간다. 보충 기회를 고려해도 통과할 수 없으면 패배한다.

페이즈 시작·전환에서 인물 컷인, 제목·대사, HP 전환, 흔들림, 충격파·입자를 표시한다. ESC로 연출을 건너뛴다. 지정 배경·음원이 없으면 그 부분만 생략한다. 기존 정답·오답·마무리 효과는 유지한다.

## 지원 카드

강도 = 카드 최고 단계 + 숙련도 강화. 숙련도 3회마다 강화 1, 최대 5다. 전투 시작 때 능력을 확정하므로 전투 중 장착 변경은 다음 전투부터 반영한다.

| 성향 | 효과 | 횟수 |
|---|---|---|
| 분석 | 오답 1개 제거, 강도 2부터 인물 힌트, 강도 3부터 오답 2개 제거 | 제출 전 전투당 1회, S 또는 지원 버튼 |
| 돌파 | 최고 3콤보 달성 시 코인 +10~30% | 자동 |
| 수호 | 강도 1은 인물 힌트, 강도 2부터 실패 위기에 새 보충 문제, 강도 3부터 힌트도 제공 | 제출 전 준비, 전투당 1회 |
| 집중 | 전투 XP 강도 × 5% 증가 | 자동 |

지원 능력은 정답 피해를 높이지 않는다. 상점은 기존 전투당 아이템 한 개 제한을 유지한다. 분석 렌즈는 아직 제외되지 않은 오답을 제거한다. 보호 부적의 오답 재도전은 전투당 한 번이다. 수호 보충 문제는 본 전투에 출제하지 않은 동일 분야 문제에서 고른다. 보충 정답은 통과 조건만 보충하며 최초 정답률·XP·해금에는 중복 반영하지 않는다.

보호 부적과 수호가 함께 준비되어 있으면 부적을 먼저 적용한다. 통과 조건이 부족하면 아직 사용하지 않은 수호 보충 기회를 적용한다. 각 기회는 한 번씩만 사용하며, 일반 전투에서 이미 목표를 채운 경우에도 기존 보호 부적의 첫 오답 재도전은 유지한다.

## 카드 획득과 NEW

- 저장 성공 후 새로 얻은 인물·단계만 획득 레이어를 연다. 중복 카드는 전체 연출을 재생하지 않는다.
- 카드 뒷면→회전→일러스트 공개 후 단계별 입자·빛을 표시한다. 1·2·3단계는 800·1,200·1,600ms다.
- 현재 장착 능력과 신규 능력·숙련도를 비교하고 즉시 장착할 수 있다. 여러 카드는 순차 확인 또는 모두 확인으로 닫는다.
- 장착은 기존처럼 인물의 보유 최고 단계를 사용한다. 신규 획득 단계가 더 낮으면 획득 단계와 실제 장착 능력을 구분해 표시한다.
- 메인, 도감 분야·목록, 장착 목록에 NEW를 표시한다. 단계별 상세를 열 때 해당 단계만 해제한다. 획득 연출·장착·도감 진입은 NEW를 해제하지 않는다.
- `.progress`의 `card.owned.<분야>|<이름>|<단계>`와 `card.new.<분야>|<이름>|<단계>`를 한 번의 원자적 저장으로 기록한다. 기존 `.txt`도 내보내며 이전 카드 파일은 그대로 읽는다. 내보내기 실패 시 `.progress`에서 복구한다.

## 연습·보상·엔딩

연습과 오답 복습은 별도 배경을 참조한다. 힌트를 화면 안에서 열고, 연속 정답 및 3·5·10콤보를 표시한다. 정답 제출은 보기를 선택해야 활성화되며, 제출 후 다음 문제 버튼으로 바뀐다. 기존 카드 확대·찢김 효과를 유지한다.

기존 정답당 XP·코인과 일반/보스 승리 보상에 난이도 가산을 적용한다. 중은 25%, 상은 50%다. 최초 승리는 일반 XP 30·코인 20, 보스 XP 120·코인 80을 더한다. 반복 승리에도 기본 보상과 숙련도를 지급한다. 세션 ID로 정산 중복을 차단한다.

연습 결과는 카드·XP·코인과 학습 기록을 표시하며 주요 행동은 다시 연습이다. 배틀 결과는 패배 재시도, 해금된 마을 보스 도전, 다음 목표, 최종 구출 엔딩으로 바뀐다. 오답 복습도 결과에서 시작할 수 있다.

교수님 구출 대사 후 결과에서 엔딩을 진행한다. GAME CLEAR에 레벨·수집률·보스 기록과 Git 기여자 기반 크레딧을 표시한다. 최초 구출 시각과 엔딩 확인을 저장하고, 계속 플레이로 메뉴에 돌아간다. 재구출 시 ESC로 돌아갈 수 있다.

## 시연

기존 F1 메뉴에 마을 보스와 GAME CLEAR 장면을 추가했다. 실제 사용자 저장과 분리된 임시 파일을 사용한다.

```powershell
.\gradlew.bat run --args="--showcase=BOSS"
.\gradlew.bat run --args="--showcase=RESULT"
.\gradlew.bat run --args="--showcase=RESCUE"
.\gradlew.bat run --args="--showcase=ENDING"
```

일반 실행은 기존처럼 `run`을 사용한다. 위 인수는 시연 진입용이며 테스트 코드를 사용하지 않는다.
