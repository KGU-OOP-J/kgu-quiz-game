# 배틀 UI 기획 및 발표 자료

## 기획: 정답으로 공격하는 인물 퀴즈 배틀

대상 사용자는 긴 인물 설명을 먼저 외우기보다 짧은 퀴즈와 수집 보상으로 학습을 시작하고 싶은 학생이다. 캠퍼스 배경에서 분야별 인물과 싸우며, 퀴즈 정답을 공격과 카드 수집으로 연결한다. 배틀 UI에서는 정답·공격·승패를 직접 표현하며, 기존 팀 스토리와 대화의 내용은 유지한다.

기획의 핵심은 **승리 조건을 충족해도 다섯 문제를 모두 학습한다**는 점이다. HP는 정답의 성취를 즉시 보여 주고, 별과 최초 정답 기록은 남은 문제도 풀 이유를 준다. 재미와 학습을 함께 목표로 하는 설계이며 실제 학습 효과가 검증되었다고 주장하지 않는다.

## 이번에 구현한 화면 구성

- **중앙 전투 공간:** 캠퍼스 배경, 인물 카드, HP, 분야별 타격과 마지막 일격 연출. 가장 중요한 인물과 상태가 중앙에 모인다.
- **왼쪽 미션 패널:** 성공까지 필요한 정답 수와 다섯 문제의 진행 기록. 정답·오답은 색상뿐 아니라 O/X 문자로 구별한다. 정보 물약의 정보는 별도의 인물 정보 패널에서 읽는다.
- **오른쪽 가방:** 기존 세 아이템의 보유 수와 효과를 함께 표시한다. 없는 아이템과 이미 사용한 상태를 구분하고, 사용할 수 없는 이유는 툴팁으로 제공한다.
- **하단 문제 카드:** 전투 공간과 같은 파란 계열의 패널에 큰 글씨로 문제와 2×2 선택지를 배치한다. 장식보다 읽기에 집중하는 영역이다.
- **답안 제출:** 선택한 번호를 제출 버튼에 다시 표시해 실수를 줄인다. 미선택 상태는 제출할 수 없고, 선택·정답·오답 상태는 서로 다른 테두리와 색상으로 표시한다.
- **자연스러운 진행:** 제출 → 정답과 설명 → 자동 다음 문제 → 승패 연출 → 기존 대화/결과 흐름. 피드백 동안 배틀 전용 진행 막대와 남은 초를 보여 주어 자동 전환을 예측할 수 있게 한다.
- **조작 편의:** 마우스 및 숫자 1–4/Enter, 키보드 포커스 표시, 긴 문제와 정보의 스크롤, 화면 크기에 따른 위치와 글자 크기 조절. 중단 시 확인창을 제공한다.

## 기능의 유용성

| 기능 | 해결하려는 사용자 문제 |
| --- | --- |
| 분석 렌즈 | 보기가 헷갈릴 때 오답 하나를 줄여 다시 생각하게 한다. |
| 보호 부적 | 틀렸다고 즉시 포기하지 않고 첫 오답을 한 번 복습한다. 보기를 재배치하고 정답 통계·학습 보상을 중복 지급하지 않는다. |
| 정보 물약 | 사전 지식이 부족한 사용자가 인물 정보를 참고하며 푼다. |
| 다섯 문제 기록 | 현재 위치와 자신의 정답·오답을 한눈에 파악한다. |
| 결과와 오답 복습 연결 | 전투의 성취를 보여 주면서 틀린 내용은 기존 오답 노트에 남긴다. |

아이템은 전투당 하나이며 공격력 두 배나 즉시 승리 기능이 아니다. 기존 저장 키와 가격을 유지해 팀의 상점·세이브와 연결한다.

## 발표에서 간략히 언급할 기술

화면은 실제 Swing 버튼·텍스트·진행 막대로 구성하고 배경과 효과만 Java2D로 그린다. 애니메이션은 Swing Timer로 갱신하며, 화면을 벗어나면 타이머를 종료한다. 전투 판정은 BattleEngine, 입력과 저장 연결은 기존 BattleGUIEvent/GameFeature, 화면은 BattlePanel이 담당한다. 배틀 전용 버튼의 표현은 BattleButton에 분리해 다른 팀 화면의 공통 버튼을 바꾸지 않는다.

## 시연 순서

1. 마을 지도에서 인물을 선택하고 중앙 카드와 미션 정보를 보여 준다.
2. 보기 선택 시 강조와 제출 번호 확인을 보여 준다.
3. 정답을 제출해 HP 감소·타격·진행 기록·자동 전환을 보여 준다.
4. 다른 전투에서 아이템 하나를 사용해 정보 열람 또는 오답 재도전을 보여 준다.
5. 3개를 맞힌 뒤에도 남은 문제를 학습하는 흐름을 보여 준다.
6. 승리 시 카드 보상과 기존 구출 대화, 교수님 패배 시 F 판정 연출을 보여 준다.

## 후속 아이디어 — 이번 구현 범위 아님

- **지식 앨범:** 정답으로 확인한 인물의 사실을 카드 뒷면에 축적해 도감이 복습 자료가 되게 한다. 도감 담당과 저장 형식 합의가 필요하다.
- **실수에서 이어지는 다음 모험:** 다음 도전에 이전 오답을 우선 출제하되 정답 위치를 섞는다. 현재 오답 노트와 출제 담당의 협의가 필요하다.
- **인물별 한 문장 보상 대사:** 해당 인물의 실제 업적과 연결된 승리 대사를 제공한다. 대사 데이터 검토가 필요하다.
- **읽기 속도 설정:** 자동 진행을 유지하면서 설명 표시 시간을 사용자 설정으로 선택한다. 공통 설정 화면 담당과 협의 후 추가한다.

이번 수정은 배틀 화면과 연결 흐름에 대한 개선이다. 메인 메뉴·지도·도감 전체를 새로 디자인한 것은 아니다.

## 마지막 일격과 조기 패배

승리 조건을 먼저 충족하면 다섯 문제를 마친 뒤 마지막 일격 연출을 실행한다. 반대로 최초 정답 수 + 남은 문제 + 가능한 보호 부적 재도전이 3 미만이면 더는 승리할 수 없으므로 상대 필살기로 끝낸다. 아직 사용하지 않은 보호 부적의 보유 여부는 GameFeature가 전달하고, 다른 아이템을 이미 사용했다면 추가 기회로 계산하지 않는다. 풀지 않은 문제는 오답·학습 기록으로 저장하지 않는다.

양쪽 마무리는 준비 → 분야별 타격 → 효과만 표시하는 2.8초 연출이다. 교수님에게 패배하면 기존 F 도장을 중심으로 낙하 확대·균열·화면 흔들림을 적용한다. 연출이 끝나야 결과로 이동하고, 도중에 화면을 떠나면 타이머와 이동 콜백이 취소된다. BattleFinishEffect는 그리기만 담당하며 판정·보상은 바꾸지 않는다.

진행 막대는 기존 공통 UI가 3px 높이에서 내부 여백 4px을 빼 채움 영역을 그리지 못하던 문제를 수정했다. BattleProgressBar로 실제 높이 전체에 그리며, 제출 즉시 가득 차고 남은 시간에 맞춰 줄어든다. 다음 제출 때 초기화하고, 마지막 일격 때는 숨긴다.

## 분야별 전투 연출

| 분야 | 일반 정답 공격 | 마지막 일격 |
| --- | --- | --- |
| 과학자 | 연속 전격과 작은 중심 폭발 | 에너지 응축 → 연속 낙뢰 → 중심 폭발과 잔류 전류 |
| 한국사 | 먹물과 갈라진 붓털 자국 | 넓게 베는 붓 형태의 참격과 먹물 비산 |
| 아이돌 | 스포트라이트·음표·음파 | 화면 전체 무대 조명과 음파 피날레 |
| 교수님 | 플레이어의 얇은 서류 뭉치 투척과 낱장 비산 | 플레이어 승리 시 두꺼운 서류 뭉치 투척, 플레이어 패배 시 교수님의 대형 F 도장 |

기존 공통 원형 파편 효과와 기억 해방/기억 붕괴 결과 문구는 제거했다. 정보 물약은 표시 이름만 변경했고 `TONIC` 저장 키와 효과는 유지한다. `BattleAttackStyle`은 분야별 그림, `BattleAttackEffect`는 일반 공격 타이밍, `BattleFinishEffect`는 마무리 타이밍을 맡는다. 공통 판정과 저장 로직은 변경하지 않는다.
